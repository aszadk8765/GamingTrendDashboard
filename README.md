# GamingTrendDashboard


## Overview
This dashboard analyzes **global video game sales trends, regional performance, genre distribution, and platform ratings** to understand market behavior and player preferences over time.

---

## Key Insights
- Global and regional sales trends by year (NA, EU, JP, Other)
- Peak gaming sales period identified through time-series analysis
- Genre-wise sales contribution with total market value
- Comparison of **critic scores vs user scores** across platforms
- Platform performance differences in gaming reception

---

## Dashboard Components
- **Line Chart:** Sales trends by region over release years  
- **Bar Chart:** Critic score vs user score by platform  
- **Donut Chart:** Genre-wise sales distribution (JP Market)  
- **KPI Indicator:** Total sales value  

---

## Tools & Technologies
- Data Visualization Dashboard Tool (Tableau)
- Video game sales dataset
- Interactive charts and filters

---

## Use Cases
- Market trend analysis in gaming industry  
- Regional and genre-based sales comparison  
- Platform performance evaluation  
- Data storytelling and portfolio showcase
